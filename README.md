# Para Dori — proyecto web

Una página romántica y nostálgica, adaptable a celular, hecha con HTML, CSS y JavaScript.

## Abrir el proyecto
1. Descarga y descomprime `para-dori.zip`.
2. Abre la carpeta `para-dori` en Visual Studio Code.
3. Abre `index.html` en el navegador. Recomendado: usar la extensión **Live Server** en VS Code y elegir “Open with Live Server”.

## Añadir fotografías
Copia tus fotografías a `assets/fotos/` y utiliza estos nombres (o cambia las rutas en `index.html`):
- `portada.jpg`
- `recuerdo-1.jpg`
- `recuerdo-2.jpg`
- `recuerdo-3.jpg`

Los archivos `.svg` incluidos son marcadores visuales. Cuando tengas tus fotos, cambia en `index.html` cada ruta `.svg` por el nombre de tu fotografía.

Consejo: usa JPG o WebP, recorta sin perder contexto y evita subir fotos privadas o que ella no querría compartir.

## Añadir la canción
El reproductor está preparado para `assets/musica/amor-del-bueno.mp3`.
Coloca ahí un archivo de audio que tengas derecho a utilizar. Si prefieres no alojar el audio, reemplazaremos el reproductor por un enlace o reproductor oficial. La música no se reproduce automáticamente: la persona debe pulsar el botón.

## Añadir tu video
Guarda tu video como `assets/video/mensaje-para-dori.mp4`. Se reproduce dentro de la página y está configurado para celulares (`playsinline`).
Recomendación: MP4 H.264, horizontal 16:9 o vertical 9:16. Para mantener una carga rápida, comprímelo y procura que no sea demasiado pesado.

## Personalizar
- Edita textos en `index.html`.
- Colores, tipografías y diseño están en `css/styles.css`.
- Interacciones y reproductores están en `js/app.js`.

## Antes de compartir
- Revisa cada texto y asegúrate de que represente lo que realmente sientes.
- Prueba la página en celular y computadora.
- No la envíes repetidamente ni la uses para presionarla. Si ella pidió distancia o no desea recibir mensajes, respeta ese límite.
- No publiques fotos ni videos privados sin consentimiento.
